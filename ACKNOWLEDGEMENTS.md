## The licence, and what it means for this repository

`focalboard/LICENSE.txt` offers the **source code** under two options: the GNU AGPL v3.0, or
a commercial licence from Mattermost. A few directories are carved out under Apache
License 2.0 — `webapp/html-templates/`, `app-config.json`, `config.json`, `webapp/i18n/`,
`server/model/` and `plugin/`, with their subdirectories. Compiled binaries produced by
Mattermost themselves are MIT, which does not apply here because nothing here is one of
those.

This project **vendors focalboard's `webapp/` source and modifies six files of it**, so it
is squarely a "modified version" in the AGPL's terms, and the Apache carve-out does not
reach it — `webapp/src/` is not one of the named directories. The exception Mattermost
offer, for an application that uses only the Admin Tools and Configuration Files and does
not adapt the source, does not apply either, for the same reason.

**Consequently: this repository is private, and publishing it would make it AGPL-3.0.** The
AGPL's obligations attach to conveying the work and to running a modified version for
others over a network; a private repository that nobody else runs does neither. Making it
public is a decision to be taken deliberately, with `LICENSE` set to AGPL-3.0 and this
paragraph replaced by the notice that licence requires — not a side effect of flipping a
visibility switch.

`focalboard/NOTICE.txt` lists focalboard's own third-party components. Everything under
`webapp/` here carries those onward unchanged.

## Shared vocabulary, on purpose

Sixty-three of the sixty-seven are names on the wire — the other four have their own
section below. They are shared because this port answers focalboard's own API for focalboard's own interface — an
interface that would not load if any of them were spelled differently. They fall into five
groups.

**Route paths** — `/api/v2/boards`, `/api/v2/boards/`, `/api/v2/clientConfig`, `/api/v2/teams/0/boards`,
`/api/v2/users/me`, `/api/v2/users/me/config`, `/api/v2/users/me/memberships`,
`/api/v2/limits` and their relatives. These are the thirteen endpoints
`focalboard-port/probes/endpoint_census.py` found the board page calling.

**Block and board field names** — `cardProperties`, `contentOrder`, `sortOptions`,
`visibleOptionIds`, `hiddenOptionIds`, `collapsedOptionIds`, `visiblePropertyIds`,
`columnWidths`, `columnCalculations`, `kanbanCalculations`, `defaultTemplateId`,
`updatedFields`, `deletedFields`, `properties`, `propertyId`, `description`,
`showDescription`, `isTemplate`, `templateVersion`, `minimumRole`, `modifiedBy`,
`boardMetadata`, `signupToken`. This is the JSON shape `src/main/java/io/akka/focalboard/api/Blocks.java`
reads and writes.

**Filter condition names** — `isNotEmpty`, `notIncludes`, `notContains`, `startsWith`,
`notStartsWith`, `notEndsWith`. The vocabulary of the rules in SPEC-001 §3; a filter written
by the interface uses these words and a port answering something else would answer nothing.

**Property types and colours** — `multiSelect`, `createdTime`, `updatedTime`,
`propColorGray`, `propColorGreen`, `propColorYellow`. Stored on the board and rendered by
the interface's own CSS classes.

**Shell response fields** — `featureFlags`, `maxFileSize`, `teammateNameDisplay`,
`telemetryid`, `enablePublicSharedBoards`, `card_limit_timestamp`, `used_cards`,
`permissions`, `system_user`, `schemeAdmin`, `schemeEditor`, `schemeCommenter`,
`schemeViewer`. The eleven endpoints in `ShellEndpoint.java` that are not this port's slice:
their shapes were read once off the running original
(`focalboard-port/probes/shell-shapes.json`), with focalboard's identifiers replaced by this
project's, and the values are this project's own. `focalboard-port/docs/scope.md` says why
they are answered rather than rebuilt.

## Four strings that are not vocabulary

**`"{block ID=<id>} not found"`**, in `BoardEntity.java`. This is focalboard's own wording,
reproduced deliberately: SPEC-001 R19 is that a patch naming an absent block answers 404
with that message, and a client comparing the two systems should read the same string.
Checked against the original by running it — `focalboard-port/probes/probe_02_server.py`
records the status and the body from the running server.

**`"NODE_ENV=production"` and `"node_modules"`**, in `build-webapp.py`. Both are npm's own
words rather than focalboard's, and they are here because this project builds the vendored
interface with focalboard's own webpack configuration, which is the command focalboard's
`package.json` gives for it.

**`"{{.BaseURL}}"`**, in `build-webapp.py`. Focalboard's server fills this Go template
placeholder into `index.html` before sending the page; a static file server does not, so the
build replaces it with nothing. The string is here in order to be removed.

## Behaviour, derived rather than copied

Everything in `src/main/java/io/akka/focalboard/domain/` was written against
`focalboard-port/specs/SPEC-001-focalboard.md`, which was written from running focalboard
and recording what it answered — not from transcribing its code. That is still derivation
and is not something to be coy about: the rules are focalboard's rules, the option order is
focalboard's option order, and the four places this port answers differently are listed in
its README under `Where it differs from focalboard`, each with the reason.
